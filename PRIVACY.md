# Privacy Note

## Scope

This notice applies only to the demo app hosted at
**https://streaming.vincentsanicolas.me**. The `streaming_gen_ui` Dart package
is a standalone UI library and does not make any API calls or collect any data
on its own.

## What happens to your messages

Messages sent in the demo are forwarded directly to the DeepSeek API for
processing. I do **not** log, store, or retain message content. I only collect
anonymous token usage statistics (counts only, no content) for cost monitoring.

## DeepSeek as a third-party processor

DeepSeek processes and stores data under its own privacy policy, including on
servers in China. Please review their policy at:

- https://cdn.deepseek.com/policies/en-US/deepseek-privacy-policy.html

For data rights requests, contact DeepSeek at **privacy@deepseek.com**.
